## Reuse vs. Spawn Decisions

| Decision | Type | Rationale |
|----------|------|-----------|
| Research Agent | **Reuse** | General market research capability is not CV-specific; one agent can serve multiple CVs. Spawn a dedicated instance only if demand blocks other CVs. |
| Content & Copy Agent | **Reuse** | Writing proposals, emails, and reports is a shared skill. Spawn if this CV's volume blocks other CVs. |
| Sales & Outreach Agent | **Spawn** | HVAC-specific outreach requires domain knowledge of the target market, personalized messaging, and dedicated pipeline management. Cannot be shared effectively. |
| Engineering Agent | **Spawn** | Building client-specific AI systems (dispatching, BI dashboards, RAG assistants) requires deep context on each client's tech stack and data. Dedicated to this CV. |
| Delivery & QA Agent | **Spawn** | Quality gating on client deliverables is critical to Stage 1 → Stage 2 conversion. Needs dedicated attention. |
