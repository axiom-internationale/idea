## Acquisition motion

Each run uses the playbook’s four inputs, specialized for law:

| Parameter | Law-firm default |
|-----------|------------------|
| **Domain** | Law firms (all practices in the ZIP — do not pre-filter to PI) |
| **Country** | USA first ([outreach_playbook.md](../../outreach_playbook.md) country table) |
| **Region** | **One ZIP / pincode per run** (city or metro only as a container for the ZIP list). First geography: New York metro. |
| **ICP description** | Small/mid law firm, managing partner reachable, 5–50 attorneys when size is known, any practice area |

### Steps (same skeleton as the playbook)

1. **Discover** — Enumerate every law firm listing in that ZIP (Maps + directories + bar lists). Target is coverage of the ZIP, not a cherry-picked practice slice.
2. **Quick screen** — Drop obvious misfits (no listing, closed, BigLaw campus, not a firm). Keep solo and small benches; docs’ floor is small/mid, not “enterprise only.”
3. **Deep research** — McKinsey-grade profile per [outreach_playbook.md](../../outreach_playbook.md) Step 3, with law-specific lenses in [report_outline.md](report_outline.md).
4. **ICP fit** — Score; ABHS sweet spot still 3.0–6.9.
5. **Reports** — Personalized Axiom Intelligence Report (Typst, 8 sections). **Client-facing prose is Priyanshu · Axiom Intelligence.** Never agentic, factory, Think Tank, General Secretary, GS, AI workforce, multi-agent, zero employees, or autonomous organization.
6. **Outreach** — Red-gated. Founding Partner approves the batch. Messages go out in his name.
